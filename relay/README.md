# Vela watch party relay

A Cloudflare Worker that keeps watch party rooms in sync. Each room is one Durable Object
(`PartyRoom`) holding the playback state, the shared title, the people in it and the last 50
chat messages. Clients connect over WebSocket to `/rooms/<CODE>`. The relay uses the hibernation
API, so an idle room costs nothing, and it forgets a room two hours after its last person leaves.

The desktop app and a browser speak the same protocol (`src/lib/watchParty/protocol.ts`, which
this Worker imports too).

## What goes through it

- The title being watched: its name, art and episode list, plus the release (torrent hash, file
  name, release group). Never stream URLs or addon addresses, because those can carry debrid keys
  and addon settings.
- Play, pause, seek and speed changes, stamped with the relay's clock.
- Display names, buffering status and chat messages.

Only the person holding the room's host key (generated by the app that creates the room) can
change the title. Anyone in the room can control playback.

## Run locally

```bash
pnpm install
pnpm dev
```

A development build of Vela (`pnpm dev` in the repository root) uses `ws://127.0.0.1:8787` when
no other relay is configured.

## Deploy

```bash
pnpm deploy
```

Release builds of Vela use the public relay at `wss://vela-party.reliutg.workers.dev`. To use your
own, build Vela with `VITE_WATCH_PARTY_RELAY=wss://<your-worker>.workers.dev`, or enter that
address under **Watch party → Sync server**.
