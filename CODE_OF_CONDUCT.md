# Código de conducta

Vela adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), cuyo texto completo se aplica a este proyecto.

En resumen: trata a los demás con respeto, acepta las críticas constructivas y céntrate en lo mejor para la comunidad. No se toleran el acoso, los insultos, los ataques personales, la publicación de datos privados de otras personas ni cualquier conducta que sería inapropiada en un entorno profesional.

Se aplica en issues, pull requests, discusiones y cualquier espacio en el que alguien represente al proyecto.

## Cómo informar

Si sufres o presencias una conducta inaceptable, contacta en privado con quien mantiene el proyecto (la cuenta de GitHub `roberthgnz`) mediante el formulario de informe privado del repositorio en la pestaña **Security** o por un mensaje directo. Los informes se tratan con confidencialidad y se responden lo antes posible. Las consecuencias siguen las pautas de aplicación del Contributor Covenant: corrección, advertencia, expulsión temporal o expulsión permanente.
